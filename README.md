# العربي من اليمين

إضافة لمتصفح كروم تخلي النص العربي يظهر من اليمين في أي موقع. تنصبها وتشتغل لحالها بدون أي إعدادات.

تفيدك في مواقع الذكاء الاصطناعي والبريد وأي موقع ما يدعم العربي. الفقرة اللي أغلبها عربي تنضبط من اليمين والإنجليزي يبقى مكانه والشيفرة البرمجية ما تنلمس.

## وش تسوي

- تضبط اتجاه الفقرات حسب نسبة الكلمات العربية فيها حتى لو بدأت الفقرة بكلمة إنجليزية
- تقلب القوائم والجداول إذا أغلبها عربي
- تتابع الردود اللي تنكتب حرف حرف
- تضبط مربعات الكتابة
- في محرر البريد تكتب الاتجاه داخل الرسالة نفسها عشان توصل صح للطرف الثاني
- فيها زر يوقفها في موقع معين لو احتجت

الإضافة ما ترسل أي نص لأي مكان وما فيها أي اتصال بالإنترنت.

## التثبيت للتجربة

1. افتح `chrome://extensions`
2. شغل وضع المطور من فوق
3. اضغط تحميل إضافة غير مضغوطة واختر مجلد `extension`

## الاختبار

```
pip install playwright
python3 test/run.py
```

يفتح كروم مع الإضافة على صفحة فيها الحالات الصعبة ويتأكد من النتيجة ويحفظ صور في `test/shots`.

## المجلدات

- `extension` الإضافة نفسها وهذا اللي ينرفع للمتجر
- `test` صفحة الحالات والاختبار
- `docs/PROJECT.md` كل تفاصيل المشروع والقرارات
